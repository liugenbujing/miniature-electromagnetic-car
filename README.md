# STC32G12K128 电磁循迹小车

基于 STC32G12K128 单片机实现的高速电磁循迹小车，采用四路电感进行路径检测，结合编码器测速与陀螺仪闭环控制，实现稳定高速循迹、直角弯处理、环岛与特殊元素识别。

---

# 项目特点

* 四路电感循迹
* 三闭环串级控制
* 增量式 PI 速度环
* 陀螺仪角速度闭环
* PD 转向控制
* 环岛状态机
* 特殊元素识别
* 负压系统控制
* TFT 实时数据显示
* 逐飞助手无线调试

# 控制结构

本车采用三闭环串级控制结构：

```text id="ubx6gr"
电感误差环
    ↓
陀螺仪角速度环
    ↓
编码器速度环
```

---

## 1. 电感误差环（外环）

根据四路电感数据计算赛道偏差：

```c id="o4qffm"
err_dianci = A_ * (num / den);
```

采用差比和算法，并结合动态权重提高弯道稳定性。

外环输出目标角速度：

```c id="v8t8hl"
target_yaw = out_position;
```

采用 PD 控制：

```c id="tvh6bw"
out_position = err * kp + diff_err * kd;
```

特点：

* 响应速度快
* 直角弯修正能力强
* 提高弯道循迹稳定性

---

## 2. 陀螺仪角速度环（中环）

利用 IMU660RA 获取车体实时角速度：

```c id="bd5m5o"
gyro_err = target_yaw - gyro_z_avl;
```

控制车辆实际转向动态。

PD 控制：

```c id="6m3d9x"
out_gyro = kp * gyro_err + kd * diff;
```

作用：

* 抑制甩尾
* 提高转向稳定性
* 减少高速振荡
* 改善直角弯表现

---

## 3. 编码器速度环（内环）

采用双编码器测速。

增量式 PI 控制：

```c id="5m3b9f"
out += kp * (e(k)-e(k-1)) + ki * e(k);
```

特点：

* 响应快
* 抗静差
* 高速稳定性较好
* 适合电磁车控制

# 误差计算

采用动态差比和算法：

```c id="2m1kjf"
num = k1 * (ad_left_x - ad_right_x)
    + k2 * (ad_left_y - ad_right_y);

den = (1-k) * (
      k1 * (ad_left_x + ad_right_x)
    + k2 * (ad_left_y + ad_right_y)
) + 1;
```

特点：

* 直线稳定
* 弯道灵敏
* 抗干扰能力较好
